# Vercel 배포 가이드

화면은 Next.js, 로그인·회원가입·매물·상담 문의는 Next 서버 라우트(`app/api/*`)가 처리합니다.
데이터는 Postgres에 저장하고, 매물 사진은 Vercel Blob에 올립니다.

> 카페24(PHP) 구조는 `server/` 폴더와 `docs/카페24_배포_가이드.md`에 그대로 남아 있습니다. 지금 기본 배포는 Vercel입니다.

## 1. 데이터베이스 연결 (필수)

Vercel 대시보드 → 프로젝트 → **Storage → Create Database → Postgres**(또는 Neon 연결)를 누르면
`DATABASE_URL`·`POSTGRES_URL` 환경변수가 자동으로 추가됩니다. 그 뒤 **재배포(Redeploy)** 하면 됩니다.

첫 요청이 들어올 때 테이블이 자동으로 만들어지고, 매물이 비어 있으면 **데모 매물 8건**이 들어갑니다.
(오픈 전에 관리자 > 매물 관리에서 "예시 매물 전체 삭제"로 지우면 됩니다.)

### 연결 전에는 (데모 상태)
- 매물 정보 페이지가 **누구나 볼 수 있게** 열리고 데모 매물 8건이 표시됩니다.
- 로그인·회원가입·상담 접수는 "데이터베이스 연결이 필요합니다" 안내를 돌려줍니다.

## 2. 환경변수

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `DATABASE_URL` 또는 `POSTGRES_URL` | ✅ | Postgres 연결 주소 (Storage 연결 시 자동 추가) |
| `AUTH_SECRET` | ✅ | 세션 쿠키 서명 키. 아무 긴 문자열 (예: `openssl rand -hex 32` 결과) |
| `ADMIN_EMAIL` | ✅ | 관리자 계정 이메일 |
| `ADMIN_PASSWORD` | ✅ | 관리자 비밀번호 (첫 배포 때 계정이 자동 생성되고, 이후에는 관리자 권한만 유지) |
| `ADMIN_NAME` | | 관리자 표시 이름 (기본값 "관리자") |
| `BLOB_READ_WRITE_TOKEN` | | 매물 사진 업로드용. Storage → Blob 연결 시 자동 추가 |
| `RESEND_API_KEY` | | 비밀번호 재설정·문의 알림 메일 발송 (없으면 서버 로그에만 남습니다) |
| `NOTIFY_EMAIL` | | 새 상담 문의를 받을 주소 |
| `MAIL_FROM` | | 보내는 사람 (예: `MediRoad <no-reply@mediroad.co.kr>`) |
| `NEXT_PUBLIC_SITE_URL` | | 사이트 주소. 비밀번호 재설정 링크에 쓰입니다 |

환경변수를 바꾼 뒤에는 반드시 **재배포**해야 반영됩니다.

## 3. 관리자 계정 만들기

1. 위 표의 `ADMIN_EMAIL`·`ADMIN_PASSWORD`를 넣고 재배포합니다.
2. 사이트에 처음 요청이 들어올 때 해당 계정이 관리자 권한으로 만들어집니다.
3. `/login/`에서 로그인한 뒤 `/admin/`으로 들어가면 됩니다.

비밀번호를 바꾸려면 로그인 화면의 "비밀번호 찾기"를 쓰거나, `ADMIN_PASSWORD`를 바꾸고 재배포하면 됩니다.

## 4. 동작 확인

| 확인할 것 | 방법 |
| --- | --- |
| 회원가입·로그인 | `/signup/` → 가입 후 `/location/` 으로 이동되는지 |
| 매물 보호 | 로그아웃 상태에서 `/location/` 접속 시 로그인으로 이동하는지 |
| 관리자 | `/admin/listings/` 에서 매물 등록·사진 업로드·거래완료 전환 |
| 상담 문의 | `/contact/` 접수 후 `/admin/inquiries/` 에 뜨는지 |
| 매물 메뉴 숨김 | `/admin/settings/` 토글 후 헤더에서 사라지는지 |

## 5. 참고

- 매물 사진은 Blob에 저장되므로 배포를 다시 해도 유지됩니다. Blob을 연결하지 않으면 업로드만 막히고 나머지는 동작합니다.
- 세션은 7일 유지되고, 로그인 10회 실패 시 10분간 차단됩니다.
- 비밀번호는 scrypt 해시로 저장하고, 재설정 링크는 1시간 뒤 만료됩니다.
