# 메디로드 요구사항 충족 여부 및 오류 검토

기준 문서: 「메디로드 수정 전달」(2026-09-29)
검토일: 2026-10-02

## 1. 요구사항 충족 여부

요청한 4개 항목은 코드와 빌드 결과에서 구현이 확인됐습니다.

| 요청 | 결과 | 반영 내용 |
| --- | --- | --- |
| 병원 2곳 로고 추가 | 충족 | 마곡 이현주산부인과의원과 올바른소아청소년과의원 로고 파일을 추가하고 홈의 병원 목록에 연결했습니다. |
| 파트너 탭·7개 페이지 신설 | 충족 | 헤더에 파트너 메뉴를 추가하고 요청한 순서대로 7개 상세 페이지를 구성했습니다. 기존 경영마케팅 페이지도 새 위치로 이동했습니다. |
| 홈 파트너 섹션 변경 | 충족 | 기존 4개 항목을 요청한 7개 분야로 교체했습니다. 넓은 화면에서는 4+3으로 배치하고, 화면 크기에 따라 열 수가 조정되며 각 항목은 해당 상세 페이지로 연결됩니다. |
| 개원 지원 소개 재구성 | 충족 | 전체 일정과 단계별 준비 사항을 중심으로 개편하고, 6단계·18개 항목의 체크리스트를 추가했습니다. |

### 주요 반영 사항

- **병원 로고:** 병원명과 동일한 파일명을 사용해 기존 로고 자동 연결 방식에 맞췄습니다. 두 이미지의 경로가 홈 빌드 HTML에 포함된 것을 확인했습니다.
- **파트너 메뉴:** 개원 및 경영 컨설팅, 온오프라인 마케팅, 인테리어 간판, 장비, 의료 소모품, 의약품 폐기물, 부동산 중개의 7개 분야를 구성했습니다.
- **마케팅 페이지 이동:** `/support/marketing/`에서 `/partners/marketing/`으로 이동하고, 기존 주소 방문자를 위한 리다이렉트 설정과 이동 안내를 추가했습니다.
- **개원 타임라인:** 전체 일정에서 준비 흐름을 확인하고, 단계별 체크리스트로 세부 항목을 점검할 수 있도록 구성했습니다. 체크 상태 저장과 진행률 표시 기능도 포함했습니다.

## 2. 오류 검토

### 확인 결과

- 빌드와 TypeScript 검사를 통과했습니다.
- 콘텐츠의 내부 경로·이미지 참조 137건에서 대상 파일 누락이 발견되지 않았습니다.
- 파트너 상세 페이지 7개의 제목, canonical 주소, 사이트맵 등록을 확인했습니다.
- 타임라인의 단계 연결과 일정 범위 데이터에서 오류가 발견되지 않았습니다.
- 로컬 브라우저에서 체크리스트를 변경한 뒤 새로고침해 저장 상태가 유지되는 것을 확인했습니다. 테스트한 체크 상태는 원래대로 복원했습니다.
- 이전·다음 버튼과 간트 막대를 통한 단계 이동이 정상 동작했습니다.
- 모바일 크기에서 메뉴 열기·페이지 이동, 비교표의 줄바꿈(390px), 타임라인 표시와 화면 넘침 여부(360px)를 확인했으며 검증한 화면에서 이상이 없었습니다.

### 수정이 필요한 내용

**편의시설 안내 FAQ의 법령 설명을 정정해야 합니다.**

`lib/partner-guides.ts`에서 2022년 개정으로 의원 등이 면적과 관계없이 편의시설 설치 대상이 되었다고 설명하고 있습니다. 2022년 개정과 면적 제한을 없앤 후속 개정을 구분하고, 기존 시설에 적용되는 경과조치도 함께 설명해야 합니다. 관련 타임라인·서비스 안내 문구도 같은 기준으로 맞추는 것이 필요합니다. [법령 개정 근거](https://law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=004627&lsRvsGubun=all)
