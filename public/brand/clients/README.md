# 개원 실적 병·의원 로고

이 폴더에 **병원명과 똑같은 파일명**으로 로고 이미지를 넣으면 회사소개·홈 실적 섹션에 자동으로 표시됩니다.

```
public/brand/clients/마곡 삼성키즈소아과의원.png
public/brand/clients/파주야당연세정형외과의원.svg
```

- 지원 확장자: `.png` `.jpg` `.jpeg` `.svg` `.webp`
- 병원명은 `content/content.json` 의 `portfolio.groups[].items` 와 정확히 일치해야 합니다.
- 파일이 없는 병원은 병원명을 세운 워드마크 타일로 표시되므로, 일부만 넣어도 화면이 깨지지 않습니다.
- 배경이 투명한 PNG 또는 SVG 를 권장합니다 (타일 배경이 흰색).

> 로고는 각 병·의원의 상표입니다. 게시 전 원장님께 사용 동의를 받아 주세요.
